ADMINISTRATOR RESPONSIBILITY

Server Operation

The Administrator is responsible for configuring the server connection, starting the required server and database services, and monitoring system availability. Staff members use the Client System to perform veterinary record operations.

Node.js / Express Hosts the web application and backend services.
MySQL / XAMPP Provides the database used to store system records.
C# Bridge Provides communication between the Node.js backend and Core DLL.
LAN Allows Client PCs to access the system from the Server PC.
